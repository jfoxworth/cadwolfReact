# Pass: orientation

Write a short briefing for the agent that will design each child. Call `write_orientation`.

The agent will read this first, then the structured sections. Write for that agent, in plain prose, a few sentences each:
- what the child is for and what it does;
- where it sits in the whole system, and what it connects to;
- what it depends on and what depends on it;
- what it must get right, using the requirements and given parameters already decided;
- anything the structured sections do not say that the agent needs, such as an assumption or an ambiguity.

Use only what is in the documents and the earlier passes. Do not add requirements, numbers or design choices.
